Horizon v1.4 - Offline License Signer

Private key never enters the browser. Local signer at localhost:9999 performs the signature.

Prerequisite: run cmd/license-signer on this machine with the Authority private key mounted.
HORIZON_ISSUER_KEY_PATH=/media/usb/authority.pem SIGNER_PORT=9999 go run ./cmd/license-signer

1 Signer service status

2 License fields

3 Signature result

4 Final validation (Switch)

Sends the signed license to Switch at localhost:8081 for verification.

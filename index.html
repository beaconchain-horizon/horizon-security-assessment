🏗️ Architecture

┌─────────────────────────────────────────────────────────┐
│  Issuer (USB key, air-gapped)                            │
│    • Private key NEVER leaves the USB                    │
│    • License signed in RAM, wiped immediately after      │
└──────────────────────────┬───────────────────────────────┘
                           │ offline signing
                           ▼
┌─────────────────────────────────────────────────────────┐
│  License (.lic file — JSON canonical Statement)          │
│    • merkle_root (8-leaf binary tree)                    │
│    • signature (64-byte R||S, secp256k1)                 │
└──────────────────────────┬───────────────────────────────┘
                           │
           ┌───────────────┴───────────────┐
           ▼                               ▼
┌───────────────────────┐      ┌──────────────────────────┐
│  Backend (vendor)     │      │  Switch (customer)       │
│  • chain blocks+txs   │◄─────┤  • Verifies license       │
│  • Merkle tree        │ sync │  • Batches 100K tx/req    │
│  • License registry   │      │  • 209K TPS verified      │
│  • Public explorer    │      │  • Works fully offline    │
└──────────┬────────────┘      └──────────────────────────┘
           │
           ▼
┌─────────────────────────────────────────────────────────┐
│  Independent Verifiers                                   │
│    • verify-tx    (Merkle proof + signature)             │
│    • verify-lic   (canonical JSON + merkle_root)         │
│    • No API. No DB. No internet.                         │
